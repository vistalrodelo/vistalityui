## 3.0.0

* Add success, warning, and info color tokens, and a shared `VIntentColors` palette.
* Add `VIntent.info`. Existing exhaustive switches on `VIntent` need an `info` branch.
* Success and warning buttons now use dedicated status colors.
* `buildTheme` applies input, button, card, dialog, snack bar, chip, and tooltip themes.
* Add alert, banner, toast, dialog, badge, tabs, pagination, breadcrumbs, popover, tooltip, progress, skeleton, empty state, bar chart, and `VTextFormField`.
* `VFilterableTable` filters rows by visible text and shows an empty message.
* Buttons expose semantics, tooltips, and a loading announcement.
* Add widget tests for theme, buttons, feedback, navigation, tables, and forms.
